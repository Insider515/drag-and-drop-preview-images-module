drag-and-drop-preview-images-module

Drop images below, or click to choose. Every file is identified by its own bytes — rename an executable to .png and it is still refused.

Compression happens on this page before anything is sent — pick a size and a quality and watch the numbers in the history below. The malware check here is a simulation so that the demo needs no API key: with it on, any file whose name contains virus is reported as malware. The real one is a VirusTotal hash lookup. The history panel at the bottom belongs to this page, not to the widget — it is not part of the package, and the button above removes it.
